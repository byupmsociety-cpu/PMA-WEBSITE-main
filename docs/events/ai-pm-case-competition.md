## Run of show (60 minutes)

| Time | Block |
|---|---|
| 0:00 | Framing and the brief: AI at each PM stage, then "You're the PM, engagement is slipping, find why and ship a fix." About 3 slides. |
| 0:07 | Discover: teams analyze the data and interview transcripts with AI |
| 0:22 | Pick one problem and write a short spec: problem, evidence, feature |
| 0:25 | Build: a no code mock, a Claude artifact, a prototype, or a PR to the dev repo |
| 0:48 | Judging: 3 or 4 teams show their work, winners picked |
| 0:58 | Wrap: winning features ship to the live site |

Teams of 2 or 3, mixing beginners with experienced builders. Every team submits a link to its work in a form so ideas that aren't shown live still count.

## Case kit (fake data)

Simulated data for the PMA site with 3 planted findings. Data must only reference pages that exist on the live site, and no fake interview should use a real member's name.

- `events.csv`: about 30 days of page views and clicks
- `users.csv`: signups and profile completion
- `feedback.csv`: free text survey answers with recurring themes
- Five short user interview transcripts

Planted findings:

1. Most visitors to the interview video library leave within 30 seconds.
2. Searches on the Resources page return nothing (for example, "case interview").
3. New members drop off at the resume upload step.
